# Implementation Plan

0. Integration spike: prove `.riv` render, C# numeric input, Rive event to C#, pointer/touch and resize on intended targets; document gaps.
1. Domain: telemetry, deterministic simulator, cooling scenario, tests.
2. Core v1: nucleus/membrane/orbitals/flow; Offline/Booting/Nominal; proximity and charge/release.
3. Overview: responsive shell, telemetry, Core-to-Uno pulse, accessibility, reduced motion.
4. Explorer: exploded Core, six selections, contextual Uno inspector, continuous updates.
5. Fault states: Elevated/Degraded/Critical/Recovering; cooling fault and recovery heartbeat.
6. Energy + Diagnostics: flow visualization and fault injection.
7. Mobile: recomposed layout, optional tilt, haptics, touch/accessibility QA.
8. Network: node model and optional synchronized authoritative C# state.
9. Developer mode + polish: ownership overlay, performance profiling, cross-platform QA, final motion tuning.
